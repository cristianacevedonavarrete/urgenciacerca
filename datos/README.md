# Datos de UrgenciaCerca

Lista de centros de salud de Chile que usa la app UrgenciaCerca. Se actualiza cada semana con una tarea automática (`.github/workflows/datos.yml`).

| Archivo | Contenido |
|---|---|
| `cl.json` | Centros de salud de Chile, combinando el Ministerio de Salud con OpenStreetMap. |
| `cl.meta.json` | Fecha de los datos, fuentes y conteos. |
| `osm_cl.json` | Respaldo de la última descarga de OpenStreetMap. |
| `revisado.txt` | Fecha de la última revisión automática. |
